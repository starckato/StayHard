IN-5 · 할 일 통합 입력 — 투두 + 루틴, 하나의 시트

현행: 투두는 할일 카드 안 인라인 입력(가볍고 좋음), 루틴은 별도 모달(이름·요일·종료일), 그리고 투두→루틴 "변환" 모달이 따로 또 존재 — 같은 개념이 입구 3개.
제안: 입구 1개 — "무엇을 할 건가" + 반복 선택 하나. '오늘만'이면 투두, 반복이면 루틴. 변환 모달은 제거(수정에서 반복만 바꾸면 됨). 저장 모델은 불변(오늘만→할일, 반복→루틴 defs) — UI 만 통합. 기존 인라인 빠른 추가도 유지 — 인라인은 '오늘만'의 지름길이 됨.
